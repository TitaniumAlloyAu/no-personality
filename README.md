# No personality／没有隐私

一个从个人主页逐渐变成网页解谜游戏的静态网站。故意保留中英文标题错位。

## 当前版本 V0.7.0
已实现：个人首页与两幅原作展示；“我”躲鼠标与渐变扫光；头像受重力掉落、弹跳滚走，砸出密码锁；关灯、火柴照明与烧出随机三位密码；启用数字轮及第一道锁；垃圾桶踢倒与♻扶正；乌鸦移动、评价与夜间单眼；原创合成提示音；搜索框文字惯性晃动、放大镜短暂放大；首次成就提示、本机进度保存与重置。

新增：返回顶部文字遇滚动掉落，点击仅归还文字；梯子缓慢上升、可退出和加速；云、雨、雪以及“我”撑伞；发光鱼掉落与拾取特写、物品栏、丢鱼入桶及踢桶找回。雨雪和鱼目前使用程序粒子与临时图形，后续更换正式素材。

V0.3 新增：头像先移动到“我”上方再落下，接触后压扁并出锁；鱼型凹槽在第一次丢鱼后出现，支持拖入或点击放入；鱼聊天引雷、焦灰擦除、金黄鱼被吃、鱼骨翻出进度板；进度条倾斜、局部模拟光标减速、迷宫和100%成就。

V0.4 新增：密码锁开后首页掉落；隐藏搜索层、拖框晃出钥匙、放大取钥匙、镜片碎裂、钥匙开权限锁、回车手风琴、网页求助三题及实际站内搜索。可从背面返回首页，首页导航也可再次进入背面。

尚未实现：正式音效与英式英语配音。部分鱼与天气仍使用占位图形。

## 运行
解压后双击 index.html，用 Edge 或 Chrome 打开。无需安装依赖、无需服务器、无需联网字体。
也可以在 VS Code 打开本文件夹，使用 Live Server 打开 index.html。后续验收以 HTTP 服务器环境为准；file:// 下的本地存储行为由浏览器决定。

## 操作
先试着把鼠标靠近“关于我”，再点击头像。关灯后，用火柴在页面中上部、略偏右的位置停留约1.5秒，烧出密码。触摸设备可点按拖动照明位置。重新开灯，点击数字轮递增，输入密码并开锁。
作品可点开，Esc 关闭；右上角开关声音。初始声音关闭，打开后仅播放简短合成提示音，目前没有语音配音。垃圾桶位于页面底部右侧。Esc 也能快速退出黑暗。
页脚“重新摆好页面”会清除本版本的本机进度。刷新恢复头像与机关初始摆放，密码和已获成就保留，方便反复试验。

## 目录
- index.html：页面结构
- style.css：视觉、动画与响应布局
- app.js：交互与浏览器本地状态
- assets/：用户提供的头像与两幅展示作品，保持原图
- docs/：开发前规划与首次 Git 操作说明

## V0.2 新交互路线
向下滚动超过150像素，顶部的“返回顶部”掉落到屏幕底部；点它，文字回到当前屏幕顶部，并出现爬梯入口。点入口缓慢爬升，可快进、退出或按Esc。雨后出现雪与鱼，鱼能点击拾取。拾取会暂停爬升，关掉奖励框后可再次爬。物品栏可以把鱼扔进垃圾桶，再踢桶找回。首次未接住的鱼在重复爬梯时可重新遇见。

## 本地预览
VS Code 按Ctrl+Shift+X，安装 Live Server（Ritwick Dey，ID ritwickdey.LiveServer），右键index.html选择Open with Live Server。若打开的是文件列表，进入no-personality再打开index.html。也可在VS Code中直接打开no-personality作为工作区根目录。此预览仅运行在本机，不会自动发布到公网。

## V0.3 试玩路线
头像点击后会先移动到“我”上方再砸中它，之后掉到底部滚走。
拾鱼→物品栏丢进垃圾桶→搜索区域出现鱼形凹槽→踢桶找回鱼→拾取→拖鱼到凹槽（也可直接点凹槽）→聊天提交任意文字或保持沉默→闪电→点黑鱼擦灰→点金黄鱼吃掉→点鱼骨翻出进度板→点进度条→点轨道圆点启动。
迷宫中鼠标控制模拟光标，先缓慢挪过倾斜直线，前方再展开迷宫；离开画布会暂停，点圆点继续，Esc可退出。达到出口显示100%，退出后恢复真实探索比例。
目前服装、鱼、骨头和闪电为程序及Emoji占位素材；没有正式鱼配音。已检查JS语法、资源与压缩包，未完成真实浏览器交互验证。

## V0.4 搜索主线
打开三位密码锁后首页下坠，露出背面。拖搜索边框来回晃动，钥匙掉到放大镜下；点放大镜三次，点击钥匙取出；页面恢复、镜片碎裂。拖钥匙到灰锁或直接点击灰锁开锁。输入后按Enter或点↵触发手风琴，再点“需要帮助！”回答三题。完成后搜索“鱼”“土豆”“关于我”等，空查询显示全部内容。返回首页后点击导航“背面的搜索”继续。已完成的阶段会保存在本机。
迷宫开始时请求指针锁定，Esc释放；不允许时可用方向键。仅在点击起点时请求，关闭或退出挑战即释放。

## V0.4.1 调整
移除首页测试搜索框及其监听，鱼型凹槽仍会在丢鱼后独立出现。背面真正搜索框保留拖动晃动。钥匙改成原创浅蓝色SVG，压在放大镜下形成重叠，放到最大时可取出。拾鱼特写暂停爬升，关闭后从原进度继续，不再直接结束梯子；Esc仍可主动退出梯子。旧存档已拿到钥匙时正确保持镜片碎裂状态。

## V0.5 比例与乌鸦支线
密码锁最大宽度320px，数字轮32×38px；权限锁采用17×20px原创SVG图标。放大镜36px，浅蓝钥匙30px，取出后放大1.6倍，整体更紧凑。
关灯后把火柴靠近乌鸦眼睛附近停留约0.85秒，乌鸦变成黑羽毛。点击羽毛穿上原创黑色服饰，服饰跟随光标。右下按钮可脱下，羽毛重新出现。吃鱼与烧乌鸦两条件满足时触发一次屠杀线梗，网页进入戒备；可点击继续或按Esc关闭。状态和装束会保存在本机，页脚重置可重新体验。
已通过语法及资源检查；浏览器里的比例、热区、服饰跟随效果还需实机确认。

## V0.6 本次确认
撤回简介填充，画廊前桌面155vh/手机125vh大片留白，使画作藏到更低处。头像碰撞期间暂停“我”的躲避，动画结束继续躲。模式按钮统一深色/浅色模式，锁提示为“一般来说，荧光字会在其他模式下出现”。火柴48px透明内圈接触乌鸦就触发羽毛动画，不再停留计时。
吃鱼且烧乌鸦后，鱼骨凹槽出现“把黑羽毛放到鱼骨旁”，可以复活鱼骨翅膀的怪乌鸦，获得生态修复成就；会消耗羽毛及服饰，保留鱼骨进度板。旧存档也可继续。本次未在真实浏览器验证布局、接触热区与复活动画。

## V0.7 生日长支线
新增birthday.js和birthday.css，更新时这两个文件必须一起复制。五题的第三题选择“当然”触发“骗子”进入派对；坐下→深色模式→点蜡烛播放合成生日旋律→再点蜡烛吹灭→森林。点树掉针叶、松果或唯一蜂窝，点蜂窝蜜蜂追猫并获得成就。多次点告示牌翻到背面找到“没有”，再点进入沙漠和风沙结尾，获得“蛋糕是个谎言”。回顾蛋糕可点击获得跟随鼠标的生日帽，退出后继续未答完的问题。完成后首页增加重玩入口。
生日场景中的乌鸦在深色模式下点击会被烧成羽毛，状态沿用主页。切回浅色模式音乐停止，切得过快会触发乌鸦吐槽（若还在）。当前生日和森林角色使用Emoji和CSS，音效是合成占位版本。安全帽装饰移除，求助文案改为“看来需要一些帮助”。
已检查两份JavaScript语法、HTML资源和压缩包；未进行真实浏览器整条支线验证。
