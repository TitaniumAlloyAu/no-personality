# V0.2 更新说明
本版本增加滚动掉落文字、梯子天气、撑伞及鱼的拾取回收，保留V0.1主线。

## 覆盖升级
关闭正在演示的网页。先备份原文件夹，将新包中的no-personality内容覆盖同名文件；保留自己的.git目录与VS Code设置。不要把新文件夹再嵌套进原no-personality中。刷新页面，必要时Ctrl+F5。无须重新安装Live Server。

## 验证与限制
已通过node --check语法检查、HTML本地资源路径检查和ZIP完整性检查；未进行真实浏览器交互验证。天气、鱼目前是临时表现素材。尚未完成凹槽、电鱼、吃鱼、进度板与后续搜索主线。

## Git提交建议
先在旧版本完成首次提交，再覆盖本包；确认修改后git add .、git commit -m "feat: add sky ladder and fish pickup branch"，最后git push。请勿将整个旧工程删除，以免丢失.git记录。
