# V0.8.1 声音与节奏

开启首页“声音：关”按钮后，页面会播放低音量原创合成背景旋律，场景变化时切换旋律；生日点烛后的旋律只在深色模式播放，和音效一起服从声音开关。乌鸦对白出现时会有短促的合成叫声，设有间隔避免连续鸣叫。故事内也可开关声音。

放慢了吹灭蜡烛到森林、沙漠到回顾、警车行驶等关键转场。节奏仍可继续调整。

未能读取此前其他对话上传的音乐文件，因此本版背景音乐是程序生成，并未包含用户上传音乐。浏览器需先点击声音按钮才能播放；声音默认为关闭。

将文件覆盖原项目，并确保新增 soundscape.js 和更新后的 index.html 一起复制，Ctrl+F5 刷新。已有进度保留。
