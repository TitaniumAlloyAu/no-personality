# V0.8：准予搜索

这次是必经主线更新：第一次在解锁后的搜索框输入非空内容并搜索，会被玉米警察带走。生日派对仍是第三问里的可错过支线。

## 新流程

第三问诚实回答 → 第五问（保留题号和可点击纸角）；选择“当然”仍可进入生日派对，返回后经历第四问。原有问题、选项和反馈保留。

真正搜索 → 哨声（需开启声音）→ 墨镜玉米与警车 → 红牌 → 执法记录小屏里的箭头上车 → 牢房。

掀海报 → 点击三次扩大墙洞 → 再点钻入隔壁牢房（前人的智慧）→ 拿痒痒挠 → 原路返回 → 选中物品栏的痒痒挠并点击铁杆三次 → 再点离开。

安全出口 → 深渊 → “安全”二字掉落，可点击 → 门板可以拆下搭一小截桥；退回按钮或横向拖动空白门框返回走廊。

逃犯出口 → 玉米核验身份 → 离场登记 → 签名第一笔就被纸抓住 → 痒痒挠让登记簿摊开 → 领取通行章 → 点击或拖放盖章 → 值班室 → 领取准予搜索 → 返回原查询的结果。放行以后正常搜索不重复逮捕，首页可重玩玉米警局。

## 其他互动与存档

窗口乌鸦仅在仍存活/已复活时出现。生日帽影响逮捕对白；门板影响身份核验对白。正字、床铺、爆米花有反馈。

中途“暂存并离开”或 Esc 可退出，下一次非空搜索继续当前场景。墙洞、海报、物品、铁杆阶段写入原存档；车辆阶段退出则转为牢房。登记室内的签字/盖章步骤不单独存档，返回时重新办理该场景。

声音默认关闭，可从首页或故事右上角开启；哨声为合成音。光标交互使用网页内的箭头表现。手机可通过点击选择物品再点击目标，不依赖拖拽；签名有按钮替代。

## 更新

覆盖原项目同名文件，保留本地 .git 与编辑器设置。新增 prison.js、prison.css，务必连同 index.html 一起覆盖。浏览器 Ctrl+F5 刷新。原存档沿用，不需要重新摆好页面；旧版已解锁搜索的玩家，下一次非空搜索直接进入新主线。

## 验证

通过 app.js、birthday.js、prison.js 语法与 ZIP 完整性检查。桌面浏览器实际走通搜索逮捕、车辆、海报墙洞、隔壁牢房、拿取工具、铁杆、两个出口、拆门、签字、痒痒挠、盖章、值班室、返回原查询；确认放行后换词搜索不再逮捕，第三问正常推进直接显示第五问，纸角可点击，首页重玩与退出可用。

浏览器测试入口仅置于预览目录，不包含在交付包中。未进行手机实机、哨声音量主观试听和最初头像至密码锁的完整回归。新增玉米和警车使用本地 SVG，牢房等场景为 CSS 绘制。
