# V0.5 更新说明

## 尺寸调整
密码锁、数字轮、背面权限锁、浅蓝钥匙和放大镜整体收紧；钥匙仍保留放大后取出开锁的尺寸差异。

## 乌鸦分支
关灯时火柴靠近眼睛0.85秒，触发剪影烟雾并留下黑羽毛。点羽毛装备原创黑色礼服与披风光标装饰，可脱下、再穿。乌鸦消失后停止其评论，不会出现隐形乌鸦说话。
已吃鱼（或已打开鱼骨板）且乌鸦被烧过，触发一次屠杀线彩蛋与生态提示；两条线先后顺序不限。提供Esc退出。当前没有怪乌鸦复活。

## 更新和检查
覆盖项目文件，保留.git和自己的设置，Ctrl+F5。旧存档可继续，先前吃过鱼也能触发组合条件。完整重玩可从页脚重置。
检查JavaScript语法、静态素材引用、ZIP完整性。未在真实浏览器验证本版动作效果。
