# V0.7.1：给派对留一点人情味

- 调整派对、森林角色位置：乌鸦最左，猫居中，鱼最右。
- 细化桌面、盘子、暖色灯光、场景留白、对白框以及移动端告示牌布局。
- 三位客人可分别点击；对白回应玩家到来、坐下、摸蛋糕、等待许愿等行为。鱼和乌鸦延续此前状态。
- 森林增加五块独立告示牌，各有连续对白和背面。最挑逗的牌子背后藏着“愿望……没有。”；玩家选择陪猫停留后再进入结尾。
- 恢复原三道问答的全部题目、选项、反馈；新增两题，共五题。“骗子”仍在第三题触发派对。反馈保留到玩家主动继续，第四题不设唯一态度答案。
- 修复吹蜡烛后旧许愿计时覆盖森林对白；复活乌鸦再次烧掉时同步状态。
- 鼠标生日帽改成独立条纹小帽，而非戴帽表情。

## 更新方式
将压缩包内 no-personality 的文件覆盖到原项目同名目录，保留本地 .git 和编辑器设置，浏览器 Ctrl+F5。存档沿用 no-personality.v01，不清除已有成就。已完成搜索的存档可从导航栏“那场生日派对”重新进入。
