# V0.8.2 乌鸦先生

接入作者提供的四幅透明 PNG：闭嘴、张嘴、展翅、深色模式眼睛。首页有对白时交替张闭嘴，被赶走时使用展翅帧，深色模式显示绿眼睛；生日场景和监狱窗口也会显示作者的乌鸦。保留火柴、羽毛、复活与既有进度逻辑。四幅原图以原始画布放入 assets，并通过 CSS 统一显示范围，不重画原稿。

桌面浏览器验证了首页素材显示、乌鸦对白以及深色模式的切换；生日、监狱、复活及触屏的组合尚未完整实测。声音开关仍需手动开启。

覆盖旧项目时，连同新增 crow-art.js、crow-art.css 和 assets 内四张 crow-*.png 一起复制，然后 Ctrl+F5；保留 .git。手机单文件仅作为预览，桌面源代码仍以 ZIP 为准。
